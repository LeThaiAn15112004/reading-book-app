# PDF file attachments — compatibility record

Results of opening Readmate-made attachment files in other readers, and other readers' attachment files in
Readmate. Test files come from `npm run spike:pdf:compat-kit -- <dir>` (see
[quickstart.md §3](../../specs/007-pdf-file-attachment/quickstart.md)).

**Rule**: a reader / version is compatible only for the checks marked `pass` below. Anything not listed, or marked
`not tested`, makes no claim. Never fill a row without actually running the check.

Checks: icon shown on the right page and spot · listed in the reader's attachment pane · opens · saved copy
byte-identical to the source · moved icon at its new spot · deleted attachment absent.
