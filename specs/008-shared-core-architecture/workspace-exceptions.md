# Workspace Exceptions (FR-017f)

**One lockfile: met.** `source/package-lock.json` is the only one under `source/`. The repo-root `package-lock.json` only covers `concurrently`, outside the workspace.

**One `node_modules`: not met, and not fully possible.** Generated from the lockfile on 2026-10-31:

| Location | Top-level packages |
|---|---:|
| `source/node_modules` | 546 entries, including nested ones |
| `apps/reading-book-desktop/node_modules` | 270 |
| `apps/reading-book-mobile/node_modules` | 442 |

## Reasons

| Group | Reason |
|---|---|
| `react`, `react-dom`, `@types/react` under Mobile | Required: Desktop stays on 18 and Expo 57 needs 19.2.3 |
| `react-native`, `expo` and packages with a React 19 peer, under Mobile | Required: they must resolve React 19 |
| `typescript` under Mobile | Mobile uses ~6.0.3 and Desktop ^5 |
| Electron and `electron-builder` tooling under Desktop | Placement from the existing lockfile; a version conflict was not checked per package |
| The rest | Not analysed per package. npm kept this placement to avoid version changes. Reducing it means deliberate updates, possibly to Desktop tools, so it was not done |

Each package listed below is therefore recorded, but not all are individually justified. This falls short of FR-017f's "justified" wording for the "rest" group. A later `npm dedupe` review could narrow it, checked against Desktop.

## Generated link

`source/node_modules/expo` is a link to `apps/reading-book-mobile/node_modules/expo`, made by Mobile's `postinstall` (`scripts/link-expo-root.mjs`). The hoisted `@expo/metro-config` must resolve `expo`, or `npx expo start` stops at load (research R10). Desktop imports no Expo code, and a package of Desktop contains no Expo package (`baseline.md`).

- Walking the lockfile from Mobile with Node-style lookup: 622 packages reached, all 61 React users resolve to 19.2.3.
- The Mobile web bundle contains React 18.3.1 and no 19.2.3.
- A real host bundle has not confirmed this yet, because of the failure in `baseline.md`; T016 repeats it.
