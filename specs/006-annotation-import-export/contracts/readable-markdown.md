# Readable copy layout (`<title>.md`)

```markdown
# <title> — <author>
Exported <date> · <n> annotations

## <Chapter title | Page N | Section k>
> <quote>

**<Kind>** · <colour> · <local date time>
Note: <comment>
```

- Strikethrough quotes use `~~quote~~`; shapes and typewriter notes have no quote, so they appear as `[Rectangle on page 3]` or the typed text.
- The `Note:` line is omitted when the comment is empty.
- Order follows the place: chapter order, page then top to bottom, offset, segment.
- Unicode is preserved exactly. The file is not importable.
