# Glossary: English → Vietnamese app terms (FR-016)

Authoritative for every Vietnamese message. One term per concept, on every screen. Tone: neutral and concise, no
"bạn" in instructions ("Chọn tệp để nhập", not "Bạn hãy chọn tệp để nhập"); sentence case; no trailing period on
buttons / menu items / labels; full sentences in messages end with a period.

## Unchanged (brand, product, format)

Readmate, EPUB, PDF, TXT, Markdown, MP3, M4A, M4B, AAC, WAV, FLAC, OGG, Opus, ZIP, Google Drive, Dropbox, OneDrive,
Whisper, FFmpeg, Foxit, Acrobat, Windows, CFI (not shown to users).

Notes

- "Delete" (file / data gone) = **Xóa**; "Remove" (from the library / list, file kept) = **Gỡ** — the distinction
  matters for referenced books.
- "Note" (audio and PDF sticky note) = **Ghi chú**; "Comment" (text attached to a highlight) = **Bình luận**.
- Diacritics use the modern placement (hòa, xóa, thủy) consistently.
